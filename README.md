# examination-system

Простой проект для задания 2. В проекте реализованы абстракция данных, инкапсуляция, наследование и полиморфизм. Есть менеджер для хранения наборов данных и простые методы поиска, фильтрации и сортировки.

Сборка и запуск с javac/java из корня проекта:

javac -d out src/com/examination/*.java
java -cp out com.examination.Main
